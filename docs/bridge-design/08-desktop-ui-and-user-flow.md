# 桌面 UI 与用户流程

## 设计目标

默认面向非技术用户，始终突出“下一步该打开哪个 Agent、复制什么、在哪个目录工作、为什么被阻止”。Git、租约、commit 和事件细节放在高级模式。

## 导航

```text
项目概览
目标与规划
任务看板
Agent 工作台
审查中心
合并队列
成本统计
决策与审计
项目设置
```

支持简洁/高级模式、中英文、键盘导航和后台长任务。

## 项目初始化向导

1. 选择 Git 项目并只读检查。
2. 选择 worktree、共享目录或只读模式。
3. 动态添加 Agent，配置能力、成本、职责和并行限制。
4. 选择 Manual、Hybrid、Automatic。
5. 选择 Strict、Balanced、Expert 并预览动作策略。
6. 预览将创建或修改的 Bridge 文件。
7. 用户确认后初始化。

## 项目概览

显示目标、任务状态、Agent 状态、worktree 健康、强模型调用、预算、合并队列和风险。顶部必须给出单一推荐下一步，例如“打开 Codex 审查 TASK-014”。

## 目标与规划

```text
用户填写目标 → Bridge 生成规划包 → 用户复制给强模型
→ 导入规划回执 → 展示任务/DAG/风险 → 用户批准或修改
```

规划未批准前不能创建大规模写任务。

## 任务看板

列：待准备、可分派、进行中、等待验证、需修复、等待审查、合并队列、完成。

任务卡显示负责人、审查人、风险、成本、范围、依赖、attempt、租约和用户操作。拖动不能绕过状态机，非法操作解释原因。

## Agent 工作台

每个 Agent 动态生成页面，显示任务、目录、租约和状态。主要按钮：复制启动提示词、打开目录、查看任务包、已交给 Agent、仍在工作、导入回执、标记阻塞。

Bridge 只有在用户点击“已交给 Agent”后才将任务设为 InProgress。

## 回执收件箱

文件变化稳定后显示解析摘要，再启动独立验证。重复、过期、错误编码、未知 lease 和格式错误进入异常区，不静默丢弃。

## 审查中心

显示目标、风险、diff、验收证据、检查结果、实现回执和已知风险。操作：复制审查提示、打开审查包、导入审查回执、用户批准、要求修复、升级深度审查。

审查 verdict 只能是 Approved、Revision Required、Blocked、Escalate。

## 合并队列

显示候选 commit、目标分支、验证、冲突预测、确认策略和回滚方式。用户可暂停、排序、重新验证、查看失败、确认合并或取消候选，但不能直接删除分支现场。

## 成本页面

按 Agent/阶段/任务展示真实或估算 token、费用、成功率和强模型调用次数。节省估算公开假设，不声称绝对准确。

## 通知

支持应用内、桌面和日志通知。等级：Info、Action、Warning、High、Critical。支持安静时段、聚合和每类开关。

## 异常恢复中心

启动扫描未完成操作、残留 worktree、脏工作区、Git 操作中断和数据库/Git 矛盾。每项提供继续、回滚、保留现场和详情，不提供不加区分的“一键全部修复”。

## 错误文案

所有错误说明：发生了什么、为什么阻止、检查了什么、用户可以做什么、是否有数据丢失风险。错误码和技术详情可折叠。

## 国际化与可访问性

- 所有 UI 文本使用翻译键；
- 项目协议语言独立于临时 UI 语言；
- 不在业务代码硬编码中文；
- 状态不能只靠颜色；
- 危险确认默认焦点取消；
- 长操作显示进度、取消和后台状态。
