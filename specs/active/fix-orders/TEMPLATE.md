# specs/active/fix-orders/ — GPT 整改指令

当审查不通过时，GPT 在此目录下创建整改指令文件。
命名格式：`fix-T001-round1.md`（第 1 轮整改）、`fix-T001-round2.md`

---

## 整改指令模板

```markdown
# 整改指令：Task N — [任务标题] — 第 X 轮

- **下达日期**：YYYY-MM-DD
- **基于审查**：review/review-T00N.md
- **执行人**：Reasonix
- **整改截止轮次**：第 2 轮（第 3 轮将升级给 GPT 亲自修复）

## 整改项

### F-01：[问题简述] 🔴阻塞
- **审查指出**：[引用审查报告中的问题]
- **期望结果**：[改完之后应该什么样]
- **涉及文件**：src/xxx.ts
- **修改建议**：[GPT 给的思路，但不强制照抄]

### F-02：[问题简述] 🟡建议
- **审查指出**：...
- **期望结果**：...
- **涉及文件**：...
- **修改建议**：...

## 整改后自检

完成所有整改后，请确认：
- [ ] 所有 🔴 阻塞项已修复
- [ ] 所有测试仍然通过
- [ ] 无新增 linter 错误
- [ ] 已 git commit，commit message 含 `[fix]` 前缀

完成后将任务状态改为 `SELF_TESTED`，等待重新审查。
```
